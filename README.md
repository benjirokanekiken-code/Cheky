# Чеки — Android-додаток

Фотографуєте німецький касовий чек, і додаток показує список товарів українською та підсумок витрат.

## Можливості
- **Розпізнавання чека з фото.** Камера, галерея або «Поділитися» фото з іншого додатка. Довгий чек можна зняти кількома фото.
- **Переклад німецька → українська.** Розшифровує типові скорочення з чеків (H-MILCH, SCHW., KL., BROETCHEN…).
- **Автоматичні категорії:** молочні, м'ясо, овочі, напої, побутова хімія, Pfand, знижки та інші.
- **Редагування.** Торкніться рядка, щоб виправити назву, ціну чи категорію. Виправлений переклад додаток запам'ятовує для наступних чеків.
- **Підсумок** за місяць, минулий місяць, рік або весь час: розбивка за категоріями та магазинами, найчастіші покупки. Підсумок можна надіслати в месенджер.
- **Перекладач** етикеток і складу продуктів.

## Два режими
| | Офлайн (за замовчуванням) | Точний (Claude) |
|---|---|---|
| Розпізнавання | Google ML Kit на телефоні | Claude API |
| Переклад | ML Kit, словник ~30 МБ завантажується один раз | Claude |
| Інтернет | потрібен лише для першого завантаження словника | потрібен |
| Ціна | безкоштовно | ваш ключ Anthropic API, приблизно кілька центів за чек |

Точний режим вмикається в **Налаштуваннях**: вставте свій API-ключ.

## Як отримати APK

### Варіант 1: GitHub (без комп'ютера з Android Studio)
1. Створіть новий репозиторій на github.com і завантажте в нього весь вміст цієї папки.
2. GitHub Actions автоматично збере APK. Збірка триває близько 5 хвилин, хід видно на вкладці **Actions**.
3. Відкрийте **Releases → «Чеки — остання збірка»** і завантажте `Cheky.apk` на телефон.
4. Встановіть файл. Android попросить дозволити встановлення з цього джерела.

### Варіант 2: Android Studio
Відкрийте папку `Cheky` в Android Studio і натисніть **Run**.
Або виконайте в терміналі: `./gradlew assembleRelease`. APK з'явиться в `app/build/outputs/apk/release/`.

## Технічно
Kotlin, Jetpack Compose (Material 3), ML Kit Text Recognition та Translate, minSdk 26 (Android 8+).
Дані зберігаються тільки на телефоні, у файлі JSON у пам'яті додатка.
